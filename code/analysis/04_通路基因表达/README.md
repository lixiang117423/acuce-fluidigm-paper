## 口径与实现说明

- **基因/通路**：92 个基因 / 20 条通路（引物面板 96 个位点 = 92 基因 + 4 内参；见主题 03 README）。
- **离群值**：按 stage × focal × neighbor × gene 用 `bioRtools::find_outliers()` 剔除，与主题 03 一致。
- **Fold change**：`log2FC = log2(mean_Mix / mean_Pure)`（线性尺度均值比）。
- **两种粒度**：① stage 层面（4 个 focal 合并，与旧版 Figure 4A/4C 口径一致）；② stage × focal 层面（用于 3C/3D）。
- **检验与校正**：Wilcoxon 秩和为主、Welch t 为对照；BH-FDR 按检验族分别校正（stage 层面按时期、stage × focal 层面按 时期 × focal）。
- **缩放**：图内表达量为基因内 0–1 缩放（与旧版 `bioRtools::scale01()` 一致），使不同基因可同图展示。
- **热图实现**：与主题 03 相同，用 `ggplot2::geom_tile` 绘制（`pheatmapColor` 未安装、`ggplotify` 转换报 gpar 错误）。

## 结果要点（2026-09-22）

### 防御通路（3A/3B、4A）

- **整体**（基因内 0–1 缩放后比较）：tillering 混种显著高于纯种（Wilcoxon P = 0.0042，n = 908 vs 351）；
  filling 无差异（P = 0.804）。与"分蘖期激活、灌浆期减弱"的叙事一致。
- **分蘖期基因水平**（stage 层面）：OsGNS1（log2FC = 1.66，P = 4.0e-4，**FDR = 0.018**）、OsPAL（1.34，P = 0.0099，FDR = 0.066）、
  OsNPR1（0.68，P = 0.034）、OsPOX223（0.93，P = 0.040）、OsSPL7（0.80，P = 0.048）方向为上调；
  OsPBZ1（P = 0.125）、OsRBBI2（P = 0.310）、OsPR5（P = 0.507）**未达显著**。
- **灌浆期基因水平**：12 个基因全部不显著（最小 P = 0.085，OsPAL，方向为下调）。

### 焦点通路（3C/3D）

- **69 分蘖期 BR + AUX**：OsBLE1 显著上调（log2FC = 1.10 即 ≈2.1 倍，P = 0.034）；OsIAA4 上调（log2FC = 3.20，P = 0.010）；
  OsGH3.2（log2FC = 0.99，P = 0.095）、OsIAA1（0.99，P = 0.078）为趋势上调；OsARF1、OsBLE2 不显著。
- **87 灌浆期 BR + SA + Drought**：OsWRKY7（log2FC = 1.26，P = 0.0077）、OsWRKY45（0.88，P = 0.049）显著上调；
  OsDHN1（1.75）、OsWRKY82（2.50）、OsWRKY114（2.16）方向上调但不显著；
  **OsBLE1 在 87 灌浆期为 +0.38（≈1.3 倍），P = 0.178，未达显著**（旧框架称 P = 0.05）。

### 独脚金内酯（4B，旧版缺失）

- 3 个基因在两个时期均不显著：tillering 的 OsD14-1 log2FC = +0.12、P = 0.077（FDR = 0.22）、OsD53 +0.02、OsD53like-1 −0.20；
  filling 各基因 P = 0.22–0.55。**"分蘖期特异激活"的说法在本次重分析中不成立**，只能表述为方向性趋势。

### 高糖通路（4C）

- **分蘖期**：OsGBSSII 显著上调（log2FC = 1.22，P = 0.0013，**FDR = 0.039**）；
  OsHXK5（+0.47，P = 0.011）、OsHXK6（+0.40，P = 0.012）为趋势（FDR = 0.066）；OsCRCT、OsHXK2 不显著。
- **灌浆期**：5 个基因全部不显著（P = 0.46–0.99），但除 OsHXK5（−0.04）外方向仍为上调。与"高糖信号跨阶段持续、灌浆期减弱"的表述基本一致。

### 通路富集（Table S3/S4）—— 重要负面结果

- 用 Fisher 精确检验（因每条通路仅 1–12 个基因，卡方不适用）在两个判据下（上调基因富集 / 显著基因富集）
  对 **全部 focal × 时期** 组合检验，**没有任何通路达到 FDR < 0.05**；
  69 分蘖期最低的原始 P 为 Auxin（4/4 基因上调，P = 0.134，FDR = 1.00），BR 为 P = 1.00；
  87 灌浆期同样无显著通路。
- 结论：**论文框架里"BR P = 0.041、AUX P = 0.005、87 灌浆期 BR P = 0.023 / drought P = 0.010 / SA P = 0.022"无法复现**
  （旧代码里也没有任何富集检验），正文不宜再使用这些数字。建议改为报告基因水平的 log2FC 与 FDR，
  并用"方向一致的基因比例"描述通路趋势。

### 高糖–防御相关性（Table S5）

- 170 个组合中 169 个可计算（1 个因表达量无变异为 NA）；**47 个组合 FDR < 0.05**（未校正 P < 0.05 的 64 个），
  且集中在**灌浆期**。最强相关：OsHXK2–OsWRKY82（r = 0.79，FDR = 7.7e-15）、OsHXK5–OsWRKY82（r = 0.55，FDR = 1.2e-05）、

### 为什么换口径

• 逐基因 Wilcoxon（脚本 01）：每个基因独立估方差 + 92 个基因做 BH 校正 → 分蘖期仅 8 个基因 FDR < 0.05、灌浆期 0 个。

• 逐通路 Fisher（脚本 02）：每条通路只有 1–12 个基因（多数 2–4 个），2×2 表几乎无检出力 → 全部阴性。

• limma（`~ 0 + group + focal`，focal 作固定区组 + 方差收缩，**并显式构造 Mix − Pure 对比矩阵**）：
在本数据上**两个时期均无基因达到 FDR < 0.05**（分蘖期 14 个基因 P < 0.05，最强 OsGNS1 logFC = 1.15、P = 0.0024；
灌浆期仅 1 个 P < 0.05）。结论：limma 与 Wilcoxon 的口径**并不冲突**，两者都只能给出名义显著信号。

> **⚠️ 2026-09-22 更正（重要）**：本 README 与 CHANGELOG 早期版本曾写"limma 下分蘖期 53/92、灌浆期 59/92 个基因
> FDR < 0.05、OsBLE1 FDR ≈ 1e-11"，**该结果是错误编码所致**——当时用 `topTable(fit, coef = "groupMix")` 取系数，
> 而在 `~ 0 + group`（无截距 + 单因子）的写法下**系数是组均值本身**（Mix 组在参考 focal 的对数均值），
> 并非 Mix − Pure 的差异，实际检验的是"该基因是否表达"这一平凡假设。改正为显式对比矩阵后，
> 正确结果是：**无基因通过 FDR < 0.05**（详见下表）。已重跑脚本 07–09 与主题 06 脚本 06，并同步更正全部记录。

• camera（limma 体系内的**竞争性基因集检验**，会校正基因间相关）：用于替代 Fisher 做通路检验，适合 2–15 个基因的小通路。

### 两点必须写进方法/讨论的局限

• 本表**没有芯片/批次变量**，无法直接校正上机批次；4 个 focal 方向 100% 一致可降低（但不能排除）批次混杂的可能。

• limma 的 logFC 是 **log2(expression + 1) 尺度、经 focal 校正**后的效应，与旧版"均值比 logFC"不是同一个量
（例如 OsGNS1 分蘖期：limma 1.15 vs 均值比 1.66），正文引用数值时必须注明尺度。

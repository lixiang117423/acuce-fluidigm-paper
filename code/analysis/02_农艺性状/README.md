**必须记住的三点数据事实**（实测核对 2026-09-22）：

1. 株高表 2518 行 `time` 为空，分析一律剔除；**focal 36 / 74 的株高记录 time 全部为空**，故不进入本主题任何分析。
2. Pure 组的 `neighbor` 已统一等于 `focal`（阶段 0 整理时设定），因此纯种均值按 `focal × time` 聚合即可。
3. 分蘖数与产量为单时点：纯种 20 株、每个混种组合 10 株（产量个别组合 7–9 株），**不存在批次/区组等随机结构**，
   故主分析用单因素 ANOVA + Tukey，而不是混合模型。

## 方法

| 脚本 | 方法 |
|---|---|
| `01` | 株高变化指数 `index = value − 同 focal × time 的 Pure 均值`；总体检验 = 混种 index 对 0 的单样本 t 检验（另做 Wilcoxon）；每个 focal 同时用旧口径 `bioRtools::anova_posthoc()`（ANOVA + Tukey 字母）与 `lmerTest::lmer(index ~ neighbor + (1 \| time))` + `emmeans`(Sidak) 两套并列；LMM 的随机截距为时间点 |
| `02` | 分蘖数 / 产量：每个 phenotype × focal 的 ANOVA + Tukey 字母；另用 `lm(value ~ focal * neighbor)` 给整体检验 |
| `03` | 三性状组合均值（16 个 focal × neighbor 组合）→ Z-score 后 `prcomp`；欧氏距离在标准化性状空间按"混种组合到该 focal 纯种点"计算 |
| `04` | 遗传距离与三性状的 Pearson 相关（主分析 = 12 个混种组合；另存含纯种的 16 组合版本对照旧图），Bonferroni 校正（α = 0.05/3） |
| `05` | Figure 1A–1F；`bioRtools::theme_prism()`、`write_data(units = "in", dpi = 500)`；P 值统一 `P < 0.001` / `P = 0.012` 定点写法 |
| `06` | 田间 PH / KGW：`lmerTest::lmer(Value ~ condition + FocalPlant + (1 \| Year))` + `emmeans` 各纯系均值与 95% CI |

注意：`03` 中必须给矩阵设行名（组合标签），否则 `scale()`/`prcomp()` 的 scores 会丢失组合标识，
导致 Figure 1D 的点与连线全部落到 NA（本次已修复并复跑验证）。

## 结果要点（2026-09-22）

- **株高**：混种整体促进株高，变化指数均值 +0.789 cm（95% CI 0.326–1.252；单样本 t 检验 P = 0.00084，Wilcoxon P = 6.5e-05）；
  Pure vs Mix 两样本 t 检验 P = 0.0060（见 Figure 1E），与手稿 P = 0.006 一致。
- **分蘖数**：整体不显著（P = 0.178），特定组合显著（见 `02_表_分蘖数与产量统计.xlsx`）。
- **产量**：整体不显著（P = 0.993）。
- **表型 PCA**：PC1 = 49.31%、PC2 = 38.85%（与旧版 Figure 1D 硬编码的轴标签完全一致，可作为 PCA 复现的直接证据）。
- **互作影响强度（标准化性状空间欧氏距离，混种到纯种）**：87（2.54）> 49（2.24）> 15（2.00）> 69（1.44），
  即 **87 受影响最大、69 最稳定**。
- **遗传距离—表型**：全部不显著（Mix 组合 n = 12：株高 r = −0.12、P = 0.699；分蘖数 r = −0.09、P = 0.772；
  产量 r = −0.33、P = 0.298；Bonferroni 校正后 P ≥ 0.89）。阴性结果稳固，支持"互作效应不能由遗传距离预测"。
- **田间补充（新）**：混种显著提高田间株高（+0.98 cm，P = 0.0115）与千粒重（+0.55 g，P = 4.6e-08），
  与室外实验"互作促进生长"的方向一致，且为独立年份/独立性状的旁证。

## 备注

- `bioRtools::anova_posthoc()` 返回的字母列为 `tukey_signif`（不是 `signif`），且其输出的 ANOVA P 值为整组共用值；
  本主题按旧口径沿用该函数以保证与旧图可比，LMM 结果作为稳健性对照另存。
- emmeans 在观测数 > 3000 时会自动关闭自由度计算（列名变为 `asymp.LCL`/`asymp.UCL`），`06` 脚本已做列名归一化处理。

对应审稿意见 **M4**（统计方法前后不一致 + 效应量尺度）与 **M10**（原始尺度效应大小与 95% CI）。

- **改动要点**：① 分蘖数 / 单株产量由"各邻体两两 Tukey"改为**计划对比**——每个 Mix 邻体组合 vs **该 focal 自己的单作对照**（emmeans 对比向量 + Dunnett 校正）；② 株高变化指数的检验单元由"每行（15 调查 × 多株，伪重复）"改为**先按每次调查取均值、再以 15 个时间点为单元**做 vs 0 的检验（纵向模型的推断结论仍以主题 06 的 Figure S9/S12 为准）；③ 接种数据用与主题 06 一致的盆级模型 `lesion ~ mode + (1|batch) + (1|pot)`，把效应换算成**原始尺度差值与百分比变化 + 95% CI**。
- **输出**：`result/02_农艺性状/13_表_计划对比与原始尺度效应.xlsx`（4 sheet：planned_contrasts_traits / height_index_contrasts / disease_effects / raw_scale_summary）。
- **关键结果（原始尺度 + 百分比变化）**：
  - **胡麻叶斑病（盆级）**：−1.195 个病斑/cm²（95% CI −2.183 ~ −0.208），**−8.87%**（95% CI −16.19% ~ −1.54%），P = 0.018（n = 1043 叶 / 96 盆）——这正是审稿人要的"原始尺度百分比变化"。
  - **稻瘟病（盆级）**：−0.183 个病斑/cm²（−0.992 ~ +0.625），−5.43%（−29.36% ~ +18.50%），P = 0.65（n = 616 叶 / 64 盆）。
  - **单株产量**：focal 15 × 邻体 69 → +4.63 g/株（0.69 ~ 8.56），**+60.0%**（+8.9% ~ +111.1%），Dunnett P = 0.017（BH-FDR = 0.41）；其余组合均不显著。
  - **分蘖数**：focal 15 × 邻体 69 → +3.15 个/株（0.08 ~ 6.22），+23.6%，Dunnett P = 0.043（BH-FDR = 0.41）；其余不显著。
  - **株高变化指数（按 15 次调查为单元）**：最强的是 **focal 87 × 邻体 15 → −8.23 cm**（95% CI −10.84 ~ −5.61，P = 4.6e-21），focal 49 × 87 → +6.07 cm、focal 49 × 69 → +7.06 cm；方向性与主题 06 的纵向模型（速率效应 +0.027 cm/天）需在正文一并交代。
- **图注/正文要跟上的三处**：① Figure 1B/1C 的字母若仍用两两 Tukey，需与正文的计划对比分开表述；② 分蘖数与产量的**显著性只在 Dunnett 口径下有个别组合**（BH 校正后均不显著），正文不宜写成"整体显著"；③ 株高指数图的误差与显著性必须标"以 15 次调查为单元"，不能再用行数当 n。
